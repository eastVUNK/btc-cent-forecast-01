Forecasts Bitcoin's price 4 hours ahead from the last 72 hours of 1-minute closes: a damped-momentum forecaster in Python (stdlib only) that shrinks short-window drift hard toward persistence and pulls slightly back toward the 72-hour median only on extreme deviations.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
